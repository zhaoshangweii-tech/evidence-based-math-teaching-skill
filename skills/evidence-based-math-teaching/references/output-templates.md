# Reusable Output Templates

## Curriculum and textbook report

1. Research question and scope.
2. Official-source and edition statement.
3. Curriculum-standard location.
4. Lesson-level competency interpretation.
5. Horizontal comparison.
6. Vertical progression.
7. Unit and lesson positioning.
8. Distinctive value and teaching boundary.
9. Source index.

## Student evidence report

1. Assessment purpose.
2. Item and construct map.
3. Coding rubric.
4. Overall data.
5. Subtype analysis.
6. Representative anonymous samples.
7. Observation, interpretation, and uncertainty.
8. Learning starting points.
9. Core difficulties.
10. Instructional responses.
11. Detail table and audit note.

## Teaching design argument

For each objective:

`evidence → learning need → objective → activity → support → success evidence`

For each activity:

|Element|Prompt|
|---|---|
|Purpose|Which diagnosed obstacle does it address?|
|Student action|What will students do?|
|Representation|What object, diagram, symbol, or language is used?|
|Teacher question|What question advances the reasoning?|
|Expected evidence|What will show learning?|
|Contingency|How will a likely misconception be handled?|

## Final delivery message

State:

1. what was completed,
2. the main evidence-based conclusion,
3. validation performed,
4. exact folder path,
5. direct links to the primary files.

Keep the delivery message short. Put depth in the artifacts.
