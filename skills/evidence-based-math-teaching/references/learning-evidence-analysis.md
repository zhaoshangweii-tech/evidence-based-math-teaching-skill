# Student Learning Evidence Analysis

## Build the rubric before counting

For each item, specify:

- target construct,
- observable indicator,
- accepted variation,
- ambiguous case rule,
- non-evidence that must not be counted,
- coding unit,
- denominator.

Example for a spatial drawing:

|Layer|Observable focus|
|---|---|
|Direction|Horizontal, vertical, or oblique|
|Position|Which surfaces or regions are intersected|
|Boundary source|Where each segment or curve comes from|
|Representation|Whether the new plane is extracted from the solid|
|Explanation|Whether the relation is justified|

Do not collapse these layers into one correct-or-incorrect score.

## Pilot and calibrate

1. Select a clear correct response, a common response, and an ambiguous response.
2. Code them with the first rubric.
3. Revise categories that require guessing.
4. Recode the pilot set.
5. Only then batch-code the full set.

When the drawing underdetermines a three-dimensional idea, code "not clearly shown" rather than guessing.

## Preserve an audit trail

Create a detail table with:

- sample ID,
- original page,
- item-level code,
- observed feature,
- interpretation,
- confidence or ambiguity note,
- candidate use in presentation.

Keep observations and interpretations in separate columns.

## Quantify carefully

- Report counts and percentages together.
- State the denominator.
- Distinguish all students from valid responses and subgroups.
- When one response can contain several features, say whether categories overlap.
- Reconcile all summary totals with the detail table.

## Select representative samples

Use samples for different purposes:

- **Starting point** — a productive idea that instruction can build on.
- **Common pattern** — a frequent observable response.
- **Misconception hypothesis** — a response suggesting a possible reasoning path.
- **Boundary case** — a sample that tests the rubric.
- **Growth case** — a response useful for comparison or revision.

Never call a sample "typical" without class-level evidence.

## Infer responsibly

Use this ladder:

1. "The student drew..."
2. "This response shows..."
3. "This may indicate..."
4. "A follow-up question or manipulation is needed to confirm..."

Avoid direct claims about what a student "believes" based only on a drawing.

## Convert evidence into teaching decisions

For each finding, complete this chain:

|Evidence|Interpretation|Learning need|Teaching response|Success evidence|
|---|---|---|---|---|
|Observed response|What it defensibly suggests|What must develop next|Task, material, or question|What students should newly do or explain|

The instructional response must address the diagnosed obstacle, not merely repeat the content.

## Protect student privacy

- Remove names, student numbers, schools, faces, and unrelated handwriting.
- Use stable anonymous IDs.
- Crop only after preserving a private original mapping.
- Do not publish raw student work to a public repository unless explicit permission exists.
